## 🌍 The Idea

Most productivity apps measure **output**.

Jareak helps you remember **growth**.

Instead of chasing endless streaks and statistics, Jareak creates a visual collection of your daily efforts—making consistency something you can actually see.

Every completed task becomes a memory.

Every memory belongs somewhere.

That place is your jar.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/jareak.git

cd jareak
```

### Install dependencies

```bash
npm install
```

### Create environment variables

Create a `.env` file in the project root.

```env
GEMINI_API_KEY=YOUR_API_KEY
APP_URL=http://localhost:3000
```

### Start development server

```bash
npm run dev
```

---

## 📦 Build for Production

```bash
npm run build
```

Run production build

```bash
npm start
```

## 🎨 Design Philosophy

Jareak is designed around one belief:

> **People don't quit because they made no progress.**
>
> **They quit because they forget how much progress they've already made.**

The interface intentionally avoids traditional productivity dashboards in favor of a warm, personal workspace that feels like a place users return to rather than a tool they simply use.
